# Regression Checklist

- Launcher opens and closes cleanly.
- Project details can be edited from the modal.
- Folder/file picker buttons open at current value or last selected folder.
- Source image previews are centered and visible.
- Model previews are centered, rotatable, and zoomable.
- Orientation manifests write to project-local refs paths.
- Optimization outputs go to staging, not directly over runtime assets.
- Existing staged optimization outputs are detected.
- Audit logs are appended in a coding-agent-readable format.
