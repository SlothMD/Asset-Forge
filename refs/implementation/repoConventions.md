# Repo Conventions

- `apps/desktop` owns the Tauri/React app.
- `apps/desktop/src-tauri` owns native commands and machine capabilities.
- `packages/core` owns shared project schema and domain logic.
- `packages/storage` owns storage adapters.
- `packages/renderer` owns deterministic rendering/export helpers.
- `packages/ui` owns reusable UI components.
- `tools` owns local helper scripts.
- `refs` owns durable agent-readable project memory.
