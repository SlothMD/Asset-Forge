# Local Setup

1. Install Node.js 20 or newer.
2. Install Rust/Cargo for Tauri development.
3. Install project dependencies with `npm install`.
4. Launch the desktop app through the repo launch script or npm workspace command.
5. Configure this-machine tools from the app settings when available.

External tools such as Blender, ImageMagick, ComfyUI, Ollama, glTF Transform, and gltfpack are optional per workflow.
